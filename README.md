# قواعد بيانات GIS

بوابة عربية مفتوحة لاكتشاف وتنظيم بيانات GIS المفتوحة حسب الدولة، التصنيف، الصيغة، المصدر، والترخيص.

## الحالة الحالية

تم رفع نسخة MVP جاهزة للنشر عبر GitHub Pages داخل مجلد:

```txt
docs/
```

## المميزات

- واجهة عربية RTL.
- تصميم Glass Tech مناسب لمشروع GIS.
- كتالوج أولي يحتوي على 20 Dataset.
- بحث وفلترة حسب الدولة والتصنيف والترخيص.
- تفاصيل Dataset داخل نافذة احترافية.
- زر **أضف مصدر** يعرض رسالة أن الميزة قيد التطوير.
- الموقع مفتوح للجميع بدون تسجيل دخول وبدون صلاحيات مستخدمين.

## تفعيل GitHub Pages

من إعدادات المستودع:

```txt
Settings > Pages > Build and deployment
Source: Deploy from a branch
Branch: main
Folder: /docs
Save
```

الرابط المتوقع بعد التفعيل:

```txt
https://mmashharawi2021-cell.github.io/gis-database/
```

## ملاحظة مهمة

المستودع حاليًا Private. إذا أردت مشاركة الرابط مع الجميع، اجعل المستودع Public أو تأكد أن GitHub Pages متاح للمستودعات الخاصة في حسابك.

## Firebase

النسخة الحالية تعمل بدون Firebase عبر بيانات داخلية في الصفحة. يمكن ربط Firestore لاحقًا بدون تسجيل دخول.
